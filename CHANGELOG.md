## [1.1.0] - Unreleased

### ✨ Highlights
- Cinnamon now handles calling much more fully inside the app, with a better dialer, a refreshed in-call screen, and a floating call bubble.
- Incoming calls are more customizable, including an optional full-screen popup.
- A new Permissions screen makes it easier to set Cinnamon as your default dialer and SMS app.
- Some call features now work more gracefully even before Cinnamon is fully set as the default app. (#33)
- You can now forward messages to another conversation without copying them by hand. (#27)
- New launcher shortcuts let you jump straight into key screens like Dialer, Messages, and Contacts. (#15)
- You can mark messages as read right from the notification shade. (#10)
- Contact editing has been improved, including better photo handling and a cleaner details experience.
- The About page and a few icons got a visual refresh 🎨

### 🛠️ Fixes
- Calls should now open in Cinnamon more reliably instead of bouncing you to the system UI.
- Incoming call notifications are less likely to stick around after you answer. (#25)
- Fixed removing a contact note. (#6)
- Fixed a crash that could happen when opening some contact websites. (#13)
- Fixed a few message and contact-related crashes, including some cases when opening conversations from contacts.
